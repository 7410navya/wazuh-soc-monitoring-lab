# Windows SOC Monitoring & Threat Detection Lab

## Overview

A hands-on SOC home lab using Wazuh to monitor and investigate Windows security events.

## Tools Used

- Wazuh
- Windows
- PowerShell
- Wireshark
- VirtualBox

## Security Events Investigated

- Event ID 4624 – Successful Logon
- Event ID 4625 – Failed Logon
- Event ID 4688 – Process Creation

## SOC Skills Demonstrated

- SIEM Monitoring
- Log Analysis
- Alert Triage
- Threat Hunting
- IOC Investigation
- Incident Response
- MITRE ATT&CK Analysis
- Network Investigation
- Event Correlation

## Investigation Workflow

Alert → Triage → Evidence Collection → Correlation → Timeline → Investigation → Verdict
